# Snap Update Manager

**Snap Update Manager** — это продвинутая графическая утилита для управления обновлениями Snap-пакетов в Ubuntu и других дистрибутивах Linux. Скрипт позволяет гибко настраивать, какие приложения могут обновляться автоматически, а какие — нет, а также предоставляет инструменты для ручного обновления и диагностики.

Утилита написана на Bash с использованием Zenity для графического интерфейса и не требует установки дополнительных зависимостей (Zenity обычно предустановлен в Ubuntu).

---

## 🚀 Возможности

*   **Глобальное управление:** Быстрое включение и выключение автоматических обновлений для всех Snap-пакетов одновременно (глобальный `--hold` / `--unhold`).
*   **Выборочная блокировка:** Удобный список с чекбоксами для блокировки или разблокировки отдельных приложений. Уже заблокированные пакеты автоматически отмечаются галочками.
*   **Разовое обновление:** Возможность обновить выбранные заблокированные пакеты «на лету», не снимая с них блокировку навсегда.
*   **Защита системных пакетов:** Системные компоненты (ядра, библиотеки, графические драйверы) помечаются значком `⚠️` и всегда идут первыми в списке, чтобы предотвратить случайную блокировку критически важных обновлений.
*   **Проверка запущенных процессов:** Перед обновлением утилита проверяет, запущено ли приложение, и предлагает закрыть его, чтобы избежать ошибок обновления.
*   **Логирование:** Все действия по разовому обновлению записываются в подробные логи (с указанием причин ошибок, если они возникли). Логи хранятся в `/var/log/snap-update-manager/` и автоматически очищаются от записей старше 30 дней.
*   **Гибкая сортировка:** По умолчанию системные пакеты отображаются первыми. При запуске с флагом `-s` можно выбрать другую сортировку (по имени или сначала заблокированные).

## 📦 Установка

1.  Скопируйте файл скрипта (например, `snap-manager.sh`) в удобное место.
2.  Сделайте его исполняемым:
    ```bash
    chmod +x snap-manager.sh
    ```
3. (Опционально) Переместите скрипт в системную папку, чтобы запускать его из любого места:
    ```bash
    sudo mv snap-manager.sh /usr/local/bin/snap-manager
    ```
    В этом случае запускать его можно командой sudo snap-manager.

## 🖥️ Использование
Скрипт требует прав root, так как управляет системными службами Snap.

Базовый запуск (быстрый режим):

```bash
sudo ./snap-manager.sh
```
В этом режиме список пакетов будет отсортирован так, что системные пакеты окажутся наверху, а меню выбора сортировки не появится.

Запуск с выбором сортировки:

```bash
sudo ./snap-manager.sh -s
```
Появится дополнительное окно, где можно выбрать сортировку: по имени (А-Я), сначала заблокированные или сначала системные.

## Основные сценарии работы

Глобальная блокировка: В первом меню выберите «🌐 Глобально: приостановить ВСЕ обновления». Это остановит автообновления для всех пакетов. В следующий раз в меню появится пункт для их возобновления.

Выборочная блокировка: Выберите «Оставить как есть (ручной выбор)». В открывшемся списке отметьте галочками те приложения, которые не должны обновляться автоматически, и нажмите «ОК».

Разовое обновление: Если пакеты заблокированы, но вы хотите обновить их вручную (например, для безопасности), выберите «Разово обновить заблокированные snap-пакеты», отметьте нужные и нажмите «ОК». Скрипт временно снимет блокировку, обновит пакет и вернет блокировку обратно.

## 📝 Логи и диагностика

Все операции по разовому обновлению логируются в папку:

```text
/var/log/snap-update-manager/
```
В случае ошибки (например, если пакет не найден на сервере или приложение не закрылось), скрипт покажет выжимку из лога в итоговом окне, а полный текст сохранит в файл.

Старые логи (старше 30 дней) удаляются автоматически при каждом запуске скрипта.

## 🛠️ Технические детали

Язык: Bash.
GUI: Zenity.

Требования: Snapd версии 2.58 или выше (для поддержки флагов --hold и --unhold). Проверить версию можно командой snap version.

Фильтр системных пакетов: Скрипт использует регулярное выражение для определения системных компонентов (core*, gnome-*, mesa-*, snapd и др.) и помечает их значком ⚠️.

---
## ⚠️ Важное примечание

Блокировка обновлений (особенно глобальная) означает, что вы перестаете получать патчи безопасности. Рекомендуется периодически проверять статус пакетов и разблокировать их для получения обновлений, особенно если речь идет о браузерах или мессенджерах.

Совет: Используйте функцию «Разово обновить» для точечного обновления важных приложений, не снимая глобальную блокировку со всей системы.
