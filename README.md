# Snap Update Manager (Python / PyQt5)

**Snap Update Manager** — графическая утилита для гибкого управления обновлениями Snap-пакетов в Ubuntu и других дистрибутивах Linux. Позволяет выборочно блокировать автообновления, вручную обновлять «замороженные» пакеты, управлять глобальным `--hold` и вести подробные логи.

Утилита написана на **Python 3** с графическим интерфейсом на **PyQt5**. В отличие от старой Bash+Zenity версии, здесь есть тёмная/светлая тема, контекстное меню, горячие клавиши и сохранение пользовательских настроек.

---

## 🚀 Возможности

*   **Глобальное управление:** быстрое включение и выключение автообновлений сразу для всех Snap-пакетов (глобальный `--hold` / `--unhold`) через меню или горячие клавиши **Ctrl+Shift+H** / **Ctrl+Shift+U**.
*   **Выборочная блокировка:** список с чекбоксами для точечной блокировки/разблокировки. Уже заблокированные пакеты автоматически отмечены.
*   **Сброс отметок:** кнопка **«↩️ Сброс отметок»** (или **Ctrl+R**, или пункт контекстного меню) мгновенно возвращает галочки к реальному состоянию системы — не нужно перезапускать программу, если случайно нажали «Выделить все».
*   **Разовое обновление:** обновление выбранных пакетов «на лету» с временной разблокировкой и автоматическим возвратом блокировки.
*   **Защита системных пакетов:** системные компоненты (`bare`, `core*`, `snapd*`, `gnome-*`, `mesa-*`, `gtk*`, `webkitgtk*`, `firmware-updater`) помечаются значком `⚠️` и по умолчанию идут первыми в списке.
*   **Проверка запущенных процессов:** перед обновлением утилита проверяет, запущено ли приложение через `pgrep`, и предлагает принудительно его закрыть.
*   **Логирование:** каждый разовый запуск обновления пишется в отдельный лог в `/var/log/snap-update-manager/`. Логи старше 30 дней удаляются автоматически при старте.
*   **Гибкая сортировка:** выпадающий список прямо в окне — «Сначала системные», «По имени (А-Я)», «Сначала заблокированные».
*   **Тема оформления:** светлая и тёмная темы (меню **Управление Snap → 🎨 Тема оформления**). Выбор сохраняется в конфиге пользователя и применяется при следующем запуске.
*   **Горячие клавиши:**
    *   **Ctrl+A** — выделить все
    *   **Ctrl+D** — снять все
    *   **Ctrl+R** — вернуть исходные отметки
    *   **Ctrl+Shift+H** — глобальный hold
    *   **Ctrl+Shift+U** — глобальный unhold
    *   **Ctrl+Q** — выход
    *   **Enter** — применить блокировку
*   **Контекстное меню** по правому клику на пакете: «Выделить», «Снять», «Переключить блокировку», «Вернуть исходные отметки».

## 📦 Установка

### Зависимости

*   Python 3.8+
*   PyQt5
*   `snapd` версии **2.58 или выше** (для поддержки `--hold` / `--unhold`)

Установка PyQt5 в Ubuntu/Debian:

```bash
sudo apt install python3-pyqt5
```

### Установка скрипта

1.  Скопируйте файл `snap-manager.py` в удобное место.
2.  Сделайте его исполняемым:
    ```bash
    chmod +x snap-manager.py
    ```
3.  (Опционально) Переместите в системную папку, чтобы запускать из любого места:
    ```bash
    sudo mv snap-manager.py /usr/local/bin/snap-manager
    ```
    После этого запуск — `sudo snap-manager`.

## 🖥️ Использование

Скрипт требует **прав root**, так как управляет системными службами Snap:

```bash
sudo ./snap-manager.py
```

При первом запуске вы увидите главное окно с:

*   **баннером глобального состояния** — 🔴 «Все обновления приостановлены» или 🟢 «Обновления активны»;
*   **строкой сортировки**;
*   **списком пакетов** с чекбоксами;
*   **нижней панелью**: «💾 Применить блокировку», «🔄 Обновить выбранные», «↩️ Сброс отметок»;
*   **меню**: «Управление Snap» и «Отметить пакеты».

### Основные сценарии работы

**Глобальная блокировка.** Меню **Управление Snap → ⛔ Приостановить все обновления** (или **Ctrl+Shift+H**). Останавливает автообновления для всех пакетов. Для возврата — **🌐 Возобновить все обновления** (**Ctrl+Shift+U**).

**Выборочная блокировка.** Отметьте галочками нужные пакеты и нажмите **«💾 Применить блокировку»**. Уже заблокированные пакеты отмечены автоматически — снимите галочку, чтобы разблокировать.

**Сброс отметок.** Если случайно нажали «Выделить все» (**Ctrl+A**) и хотите вернуться к тому, что реально заблокировано в системе — нажмите **«↩️ Сброс отметок»**, **Ctrl+R** или выберите пункт в контекстном меню. Никакого перезапуска программы не требуется.

**Разовое обновление.** Отметьте пакеты, нажмите **«🔄 Обновить выбранные»**. Скрипт временно снимет блокировку, обновит пакет и вернёт блокировку обратно. Прогресс отображается в диалоговом окне; при обнаружении запущенного процесса будет задан вопрос о его принудительном закрытии.

## 🎨 Тема оформления

Переключение между светлой и тёмной темами — в меню **Управление Snap → 🎨 Тема оформления**. Выбор сохраняется в:

```text
~/.config/snap-manager/settings.ini
```

(или `$XDG_CONFIG_HOME/snap-manager/settings.ini`, если переменная задана).

При запуске через `sudo` настройки всё равно пишутся в домашнюю папку **реального пользователя** (берётся из `SUDO_USER`), а не в `/root`.

## 📝 Логи и диагностика

Все операции по разовому обновлению логируются в:

```text
/var/log/snap-update-manager/update-YYYYMMDD_HHMMSS.log
```

В случае ошибки (пакет не найден на сервере, приложение не закрылось и т.п.) скрипт покажет выжимку из лога в отдельном окне с прокруткой, а полный текст останется в файле.

Старые логи (старше 30 дней) удаляются автоматически при каждом запуске.

## 🛠️ Технические детали

| Параметр | Значение |
|---|---|
| Язык | Python 3 |
| GUI | PyQt5 |
| Минимальная версия snapd | 2.58 (для `--hold` / `--unhold`) |
| Конфиг | `~/.config/snap-manager/settings.ini` |
| Логи | `/var/log/snap-update-manager/` |
| Фильтр системных пакетов | regex `^(bare\|core.*\|snapd.*\|gnome-.*\|mesa-.*\|gtk.*\|webkitgtk.*\|firmware-updater)$` |

Проверить версию snapd:

```bash
snap version
```

При старте скрипт сам проверяет версию и, если она ниже 2.58, показывает ошибку и завершает работу — без `--hold` утилита бесполезна.

## ⚠️ Важное примечание

Блокировка обновлений (особенно глобальная) означает, что вы перестаёте получать патчи безопасности. Периодически проверяйте статус пакетов и разблокируйте их для получения обновлений — особенно браузеры и мессенджеры.

**Совет:** используйте «🔄 Обновить выбранные» для точечного обновления важных приложений, не снимая глобальную блокировку со всей системы.

## 📜 Лицензия

Скрипт распространяется свободно, без гарантий. Используйте на свой страх и риск — особенно глобальный `--hold` на критичных системах.

### Что изменилось по сравнению с Bash-версией

*   **Язык и GUI:** Bash + Zenity → Python 3 + PyQt5.
*   **Тёмная тема** с сохранением выбора пользователя (раньше не было).
*   **Сброс отметок** одним нажатием (`Ctrl+R`) — не нужно перезапускать программу.
*   **Горячие клавиши** на все основные действия.
*   **Единый интерфейс** — всё в одном окне, без цепочки диалогов Zenity.
*   Флаг `-s` больше не нужен — сортировка переключается прямо в окне.
*   Фильтр системных пакетов расширен (`bare`, `firmware-updater`, `webkitgtk*`).
